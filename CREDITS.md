# Credits

Hexathlon was created by **Adrian Eyre**
(<https://github.com/adrianeyre/hexathlon>). The in-game Credits (Settings >
Credits) start with the same.

All art, animation, music, sound effects, the title and the name are original
work made for Hexathlon. Nothing is traced, sampled or derived from any other
game (see `docs/architectural-decision-record/`).

This file records every piece of third-party material that ships with the game
or is used to make it, with its licence. Add a row before merging anything that
uses third-party work.

## Made for Hexathlon

Original material that ships with the game, listed so its provenance is on record.

| Item | Used for | Where | Notes |
|---|---|---|---|
| Hexathlon pixel font | All on-screen text (HUD, menus) | `src/render/font.ts` | 5x7 glyphs drawn in-house as code. No font file is loaded; the whole font is about 7 KB of source. MIT, like the rest of the game. |
| Sound effects and jingles | Pistol, footsteps, crowd, finish, menus | `src/audio.ts` | Synthesised with Web Audio at runtime. No samples. Melodies written for Hexathlon. |
| Announcer | "On your marks", "Get set", "Foul" and the other callouts | `src/voice.ts`, `data/callouts.json` | Spoken at runtime by the browser's built-in speech synthesis (the Web Speech API), in whatever voice the player's system provides. No recordings are shipped. Phrases are generic athletics calls. |
| Hexathlon theme | Title screen music | `src/audio.ts` (`THEME`) | An original eight-bar march for square-wave lead and triangle bass, written for Hexathlon. Not based on any existing melody. |
| Intro fanfare | Opens an Arcade Session | `src/audio.ts` (`INTRO_FANFARE`) | An original eight-bar piece in C major, written for Hexathlon: a snare roll and pickup call, a bouncy syncopated tune, a call-and-answer climb and a run up to a trill and a held top C. Square-wave lead and harmony, an oom-pah triangle bass and a synthesised drum kit (kick, snare, hi-hat). Not based on any existing melody. |
| Sprites and scenery | Athletes, kits, stadium, crowd, track and every Event's props | `src/art/` | Pixel art drawn in-house as code, following `docs/style-guide.md`. Nothing traced or derived from another game. Accent colours are from the Okabe-Ito colour-blind-safe set (Okabe and Ito, 2008), which are plain colour values. |
| Title artwork | Title screen | `src/render/title-art.ts` | Drawn in-house as code. |
| Logo and icons | Favicons, Apple touch icons, install icons, Windows tiles and the pinned-tab mask | `favicon.ico`, `icons/`, `browserconfig.xml`, generated by `tools/make-icons.ts` from `tools/icon-art.ts` | Original, code-defined vector art, rendered to SVG and to anti-aliased PNG by the scripts. |
| Social card and screenshots | The share image and the README and docs screenshots | `images/social-card.png`, `docs/screenshots/`, captured by `tools/screenshots.ts` | Taken from the game itself, with the logo and the game's own pixel font. |
| Style guide images | Review images in `docs/style-guide/` (not shipped) | generated by `tools/sprite-sheet.ts` | Renders of the code-defined art above. |
| Colour-vision simulation | Palette checks (development only) | `tools/colour-vision.ts` | Implements the published matrices of Machado, Oliveira and Fernandes (2009); no third-party code. |
| Rival pace variation | The Rival's seeded jitter | `src/sim/rival.ts` (`nextRandom`) | The Mulberry32 generator by Tommy Ettinger (public domain), written out from its published description. |
| Noise for drums and the crowd | The one-second noise buffer | `src/audio.ts` | George Marsaglia's xorshift32 generator ("Xorshift RNGs", 2003), from the published algorithm. |
